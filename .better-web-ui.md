## Design Context

### Users

Spanish-speaking household members using HogarIA to coordinate pantry, meals, shopping, and household settings from desktop or mobile. Household managers also configure shared AI providers.

### Brand Personality

Practical, warm, and direct. Prefer calm confidence over marketing language. UI copy uses the existing Spanish/English i18n dictionaries.

### Aesthetic Direction

Preserve HogarIA's warm neutral surfaces and orange/green semantic palette, spacing/type tokens, and shared component geometry. Keep forms and settings minimal, aligned, and task-focused; avoid redundant headings/help, nested cards, decorative AI motifs, and extra confirmation controls. Keep related notices adjacent to the control they explain.

### Implementation Defaults

Use the detected stack: Angular standalone components, shared UI components, project SCSS tokens, and existing Angular forms/i18n patterns. Keep validation in existing helpers and API requests in existing services. Do not add a component library or dependencies for routine UI.

### Design Principles

- Make one primary action obvious; keep secondary actions quiet.
- Use one concise instruction and only the help needed to finish the task; give examples only where they reduce ambiguity.
- Group controls and notices by proximity; use accessible disclosure for secondary details.
- Reuse shared components and geometry; distinguish states with semantic color or icon, not arbitrary size changes.
- Design mobile as a focused flow, not a compressed desktop form or a long stack of panels.
